# 🏛️ پادکست زنگ تاریخ | Zangetarikh Podcast
> **لندینگ‌پیج رسمی و لینک بیو (Link-in-Bio) با تم تاریخی-باستانی**  
> تهیه، تدوین و اجرا: **میلاد نصرتی**

این پروژه یک صفحه فرود تک‌صفحه‌ای فوق‌العاده مدرن، سریع، چشم‌نواز و کاملاً ریسپانسیو (Mobile-First) است که اختصاصاً برای پادکست **«زنگ تاریخ»** و متناسب با استفاده در لینک بیو اینستاگرام، تلگرام و شبکه‌های اجتماعی طراحی شده است.

---

## ✨ ویژگی‌های برجسته و هویت بصری

1. **تم اصیل تاریخی-باستانی (Antique Gold & Deep Obsidian):**
   - پس‌زمینه تیره ذغالی و سرمه‌ای باستانی (`#07090E`) همراه با گرادیان‌های طلایی کهنه (`#D4AF37`)، برنز مایل به مسی (`#C57D48`) و افکت گلس‌مورفیسم شفاف (Glassmorphism).
   - لوگوی دایره‌ای با حلقه چرخان فلکی/باستانی (Astrological Solar Rings) و هاله نورانی طلایی.

2. **افکت‌های بصری و تعاملی:**
   - **ذرات معلق گرد و غبار زرین (Golden Dust Canvas):** شبیه‌سازی حرکت روان و آرام غبار تاریخ و جرقه‌های طلایی در پس‌زمینه با Canvas بهینه و سبک بدون افت فریم (با توقف خودکار هنگام عدم حضور در تب برای صرفه‌جویی در باتری گوشی).
   - **نوای زنگ تاریخی (Web Audio Chime):** سنتز صدای طنین‌انداز زنگ باستانی با هارمونیک‌های زنگوله از طریق Web Audio API مرورگر بدون نیاز به دانلود فایل‌های صوتی سنگین.
   - **گردونه خرد و کلام تاریخ (Historical Wisdom):** نمایش نقل‌قول‌های متفکران و مورخان بزرگ تاریخ (ابن خلدون، ویل دورانت، فردوسی، کوروش بزرگ و...) همراه با دکمه چرخش نقل‌قول.
   - **اشتراک‌گذاری آسان (Native Web Share & Copy):** اشتراک‌گذاری مستقیم در اپلیکیشن‌های موبایل و کپی لینک به همراه پیام پاپ‌آپ (Toast) طلایی شکیل.

3. **ساختار بخش‌ها:**
   - **هدر و پروفایل:** لوگوی باکیفیت رسمی پادکست، نام پادکست، زیرعنوان، نام میلاد نصرتی و متن فلسفه پادکست به همراه تگ‌های موضوعی.
   - **بخش ویژه آخرین اپیزود:** معرفی قسمت تازه (فصل ۵: سلوکیان و اشکانیان) با دکمه شنیدن سریع.
   - **بخش متمایز یوتیوب (Spotlight):** کارت جذاب با استایل نئونی برای ترغیب مخاطبان به سابسکرایب کانال یوتیوب زنگ تاریخ.
   - **پلتفرم‌های شنیدن پادکست:** کست‌باکس (Castbox)، اسپاتیفای (Spotify)، اپل پادکست (Apple Podcasts)، تلگرام (Telegram) و پخش تحت وب (تهران پادکست).
   - **راه‌های ارتباطی و حمایت مالی:** صفحه اینستاگرام، دونیت در حامی‌باش (Hamibash) و ایمیل مستقیم.
   - **فوتر:** سخن ماندگار تاریخی و نشان حق نشر.

## 🚀 راهنمای استقرار روی GitHub Pages (در کمتر از ۲ دقیقه)

این پروژه کاملاً خالص (Pure HTML5 / CSS3 / Vanilla JavaScript) است و هیچ‌گونه وابستگی یا ابزار بیلد (Build Tool) نیاز ندارد؛ بنابراین مستقیماً روی گیت‌هاب پیجز اجرا می‌شود:

### روش اول: از طریق دستورات Git (ترمینال)
```bash
# ۱. رفتن به پوشه پروژه
cd e:/zangetarikh

# ۲. مقداردهی اولیه مخزن گیت
git init
git add .
git commit -m "feat: Initial commit for Zangetarikh Link-in-Bio landing page"

# ۳. اتصال به مخزن گیت‌هاب (نام کاربری و ریپازیتوری خود را جایگزین کنید)
git branch -M main
git remote add origin https://github.com/USERNAME/zangetarikh.git
git push -u origin main
```

### روش دوم: فعال‌سازی در پنل گیت‌هاب
1. در صفحه مخزن خود در GitHub به بخش **Settings** بروید.
2. از منوی سمت چپ، روی گزینه **Pages** کلیک کنید.
3. در بخش **Build and deployment**، گزینه **Branch** را روی `main` و شاخه را روی `/ (root)` قرار دهید و روی **Save** کلیک کنید.
4. پس از ۱ تا ۲ دقیقه، لندینگ‌پیج شما روی آدرس زیر در دسترس خواهد بود:
   ```
   https://USERNAME.github.io/zangetarikh/
   ```
