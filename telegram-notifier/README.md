# 🤖 راهنمای راه‌اندازی ربات تلگرام برای مانیتورینگ کلیک‌ها

با این سیستم، هر بار که کاربری روی هر یک از لینک‌های صفحه شما (کست‌باکس، یوتیوب، اسپاتیفای، تلگرام، اینستاگرام، حامی‌باش و...) کلیک کند، یک پیام زیبا و حاوی مشخصات در تلگرام برای شما ارسال می‌شود:

```text
🔔 کلیک جدید روی لینک‌های زنگ تاریخ!

🎯 بخش: کانال رسمی یوتیوب
🔗 آدرس مقصد: https://www.youtube.com/@zangetarikhpodcast
📱 دستگاه: موبایل (iOS - iPhone)
🌐 ورودی از: اینستاگرام (@zangetarikhpodcast)
⏱️ حضور در صفحه: ۱۴ ثانیه
📅 زمان: یکشنبه، ۴ آبان ۱۴۰۵ - ۱۶:۴۵
```

---

## 🔑 گام اول: ساخت ربات و دریافت Chat ID (تنها ۱ دقیقه)

1. در تلگرام وارد ربات **[@BotFather](https://t.me/BotFather)** شوید و دکمه Start را بزنید.
2. دستور `/newbot` را ارسال کنید.
3. یک نام برای ربات انتخاب کنید (مثلاً: `Zangetarikh Alert`).
4. یک یوزرنیم با پسوند bot انتخاب کنید (مثلاً: `zangetarikh_alert_bot`).
5. **توکن ربات (HTTP API Token)** به شما داده می‌شود (مثلاً: `7123456789:AAH...`).
6. ربات ساخته‌شده خود را باز کرده و دکمه **Start** را بزنید تا ربات اجازه پیام دادن به شما را داشته باشد.
7. برای پیدا کردن **Chat ID** عددی خود، وارد ربات **[@userinfobot](https://t.me/userinfobot)** شوید؛ عدد مقابل `Id` را کپی کنید (مثلاً: `123456789`).

## ⚡ گام دوم: انتخاب روش فعال‌سازی

### روش ۱: استفاده از Google Apps Script (۱۰۰٪ رایگان، بدون فیلتر، بسیار امن - پیشنهاد ما)
> **چرا این روش؟** سرورهای گوگل در ایران فیلتر نیستند، بنابراین حتی کاربرانی که بدون VPN صفحه شما را باز می‌کنند، کلیکشان ثبت شده و پیام به تلگرام شما می‌رسد. همچنین توکن شما در گیت‌هاب عمومی لو نمی‌رود.

1. وارد سایت [script.google.com](https://script.google.com) شوید (با حساب گوگل خود).
2. روی **New Project** کلیک کنید.
3. محتوای فایل `google-apps-script.js` در همین پوشه را کپی کرده و جایگزین کدهای موجود کنید.
4. مقادیر `BOT_TOKEN` و `CHAT_ID` را در خطوط اولیه کد وارد کنید.
5. از بالا سمت راست روی **Deploy** و سپس **New deployment** کلیک کنید.
6. آیکون چرخ‌دنده (Select type) را بزنید و **Web app** را انتخاب کنید:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
7. روی **Deploy** کلیک کنید و دسترسی‌ها را تایید (Authorize) نمایید.
8. در پایان، آدرس **Web app URL** را کپی کنید.
9. فایل `telemetry-config.js` در ریشه پروژه را باز کرده و آدرس را در متغیر `WEBHOOK_URL` قرار دهید:
   ```javascript
   WEBHOOK_URL: "https://script.google.com/macros/s/AKfycb.../exec",
   ```

---

### روش ۲: اتصال مستقیم تلگرام (بدون وب‌هوک)
اگر نمی‌خواهید از وب‌هوک گوگل استفاده کنید و مایلید مستقیماً تست کنید:
1. فایل `telemetry-config.js` را باز کنید.
2. در بخش `DIRECT_TELEGRAM`، مقادیر `BOT_TOKEN` و `CHAT_ID` را قرار دهید:
   ```javascript
   DIRECT_TELEGRAM: {
     BOT_TOKEN: "توکن_ربات_شما",
     CHAT_ID: "آیدی_عددی_شما"
   }
   ```
> ⚠️ **توجه:** در صورت استفاده مستقیم، اگر مخاطب از ایران بدون فیلترشکن صفحه را باز کند، ممکن است مرورگر به دلیل فیلتر بودن دامنه تلگرام نتواند درخواست را ارسال کند. به همین دلیل روش اول (وب‌هوک واسط گوگل) برای ایران بسیار کارآمدتر و مطمئن‌تر است.
